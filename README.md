# BLR Center — Strategy and Next Steps

Interactive slide deck for the BLR Center for Flourishing Communities social media strategy review.

## Run it

Open `index.html` in any browser. No build step. Arrow keys, Page Up/Down or the side buttons move between slides; tap cards, map pins, phase buttons and roadmap phases to open them. The decisions slide is a live checklist.

## Files

- `index.html` — 16 slides
- `styles.css` — design tokens and layout
- `app.js` — navigation and interactivity

## Images

Background photography is loaded from Unsplash (free license) and needs an internet connection. Replace the `background-image` URLs in `index.html` with BLR's own event photos when ready.
